# Hero video

Fișierul `hero-house.mp4` inclus acum este clipul Pexels selectat pentru hero. Poate fi înlocuit ulterior cu un film propriu al Scandinavian Smart House, păstrând același nume.

Recomandare: un clip fără audio, 1920×1080 sau mai mare, comprimat WebM/MP4 pentru web (ideal sub 8 MB). Pagina are deja poster-ul foto ca fallback pentru conexiuni lente și pentru utilizatorii care preferă mișcare redusă.
